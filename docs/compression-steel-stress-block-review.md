# 압축철근 콘크리트 치환 공제 기준 검토

작성일: 2026-06-03

## 1. 검토 배경

B5-I 예제의 평형상태 계산에서 프로그램의 평형편심이 예제보다 크게 산정되었다.

- 예제: `eb = 968.28 mm`
- 프로그램 기존값: `eb ≈ 973 mm`

평형편심은 다음 식으로 계산된다.

```text
eb = Mb / Pb * 1000
```

따라서 차이는 `Pb`, `Mb`를 구성하는 `Cc`, `Cs`, `Tt`, `Mc`, `Ms`, `Mt` 중 하나에서 발생한다.

## 2. 기존 프로그램 방식

기존 프로그램은 압축철근의 콘크리트 치환 공제를 다음 조건에서만 적용했다.

```text
철근 위치 y >= 등가압축블록 하단 위치
```

즉, 철근이 `a = beta1 * c` 깊이의 등가 직사각형 응력블록 안에 들어온 경우에만 다음 식을 적용했다.

```text
Fs = (fs - 0.85 * eta * fcd) * As
```

반대로, 중립축 기준으로는 압축측에 있으나 등가블록 밖에 있는 철근은 단순히 `fs * As`로 계산했다.

## 3. 쟁점

등가 직사각형 응력블록은 실제 콘크리트 압축응력분포를 국부적으로 그대로 표현한 것이 아니라, 실제 압축응력분포와 같은 결과력 및 도심을 갖도록 등가화한 모델이다.

따라서 `a = beta1 * c`는 실제 압축영역 전체 중 응력이 존재하는 유일한 영역이라기보다, 실제 비선형 응력분포를 단순화한 등가 깊이로 보는 것이 타당하다.

이 관점에서는 압축측 철근이 차지한 콘크리트 면적의 중복 공제도 등가블록 내부 여부가 아니라 중립축 기준 압축측 여부로 판단하는 것이 더 일관된다.

## 4. 조사 근거

ScienceDirect의 철근콘크리트 압축철근/기둥 설명은 Whitney 등가 직사각형 응력분포가 실제 곡선형 콘크리트 압축응력분포를 대체하는 것이며, `a/c = beta1`은 실제 분포와 등가분포의 면적과 도심을 맞추기 위한 계수라고 설명한다.

참고: https://www.sciencedirect.com/topics/engineering/compression-reinforcement

Newton Excel Bach의 등가 응력블록 설명도 비선형 응력-변형률 분포와 같은 면적 및 레버암을 갖도록 직사각형 응력블록 계수를 정한다고 설명한다.

참고: https://newtonexcelbach.com/2011/10/19/equivalent-stress-blocks/

StructuralEngineering 커뮤니티의 이중철근보 토론에서는 압축철근 계산에서 철근이 치환한 콘크리트 면적을 공제해야 한다는 실무적 논의가 있다. 해당 토론에서는 Whitney stress block을 사용하면서 압축철근이 차지한 콘크리트 면적 공제를 빠뜨리면 오류가 된다고 설명한다.

참고: https://www.reddit.com/r/StructuralEngineering/comments/1qlvjv5/analysis_of_doubly_reinforced_beams/

## 5. 판단

본 프로그램에서는 다음 기준을 채택한다.

```text
철근 변형률 es_i > 0  -> 압축측 철근
철근 변형률 es_i <= 0 -> 인장측 철근
```

압축측 철근은 등가 콘크리트 응력과 중복되는 콘크리트 면적을 공제한다.

```text
Fs_i = (fs_i - 0.85 * eta * fcd) * As_i
```

인장측 철근은 콘크리트 인장응력을 무시하므로 공제 없이 철근력만 계산한다.

```text
Fs_i = fs_i * As_i
```

## 6. 적용 범위

이 기준은 다음 계산에 동일하게 적용한다.

- P-M 상관도 계산 엔진
- 평형상태 계산
- 작용편심에 대한 Trial 단면강도 계산
- 검토보고서의 `Cs`, `Tt`, `Ms`, `Mt` 산출

순압축 상태는 모든 철근이 압축측이므로 기존과 같이 다음 형태를 유지한다.

```text
P0 = (0.85 * eta * fcd) * (Ag - Ast) + fyd * Ast
```

## 7. 기대 효과

압축측 철근 중 등가블록 밖에 위치한 철근도 콘크리트 치환 공제가 적용되므로 `Cs`가 기존보다 감소한다. 이는 B5-I 예제의 평형상태 `Cs`와 더 가까운 방향이다.

다만 예제 프로그램이 사용하는 고강도 콘크리트 응력계수, 철근 배치 세부좌표, 반올림 방식이 완전히 동일하지 않으면 `Pb`, `Mb`, `eb`가 완전히 일치하지 않을 수 있다.

## 8. 결론

등가 직사각형 응력블록은 실제 압축영역 전체의 콘크리트 압축응력을 등가화한 모델이므로, 압축철근의 콘크리트 치환 공제는 등가블록 내부 여부가 아니라 중립축 기준 압축측 여부로 판단하는 것이 더 합리적이다.

따라서 본 프로그램은 사용자의 판단에 따라 압축측 철근 전체에 대해 콘크리트 치환 공제를 적용하도록 수정한다.
